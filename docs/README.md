# kata

kata is the design system of sakuzu's drawing tools. These chapters
describe its rules and its values. Read them in order: each one builds on
the ones before it.

1. [Principles](principles.md). The six rules behind every value and
   component, and the words the documents use.
2. [Scale](scale.md). The single root φ, the steps, the seven sizes and the
   type roles, with their formulas and values.
3. [Tokens](tokens.md). The CSS custom properties for spacing, type, color
   and the rest, and the base CSS.
4. Measuring (coming). Distances are measured from the edge of what is
   visible.
5. Layout (coming). Containers, rows, gaps and the three widths.
6. [Components](components/README.md). How to use the Svelte components,
   then one page per component: its props, its height, padding and states,
   and a live example.
7. Workbench (coming). One page per part of a drawing application: its
   boundary with the application, and a live example.
8. Patterns (coming). Common arrangements of components: modal, menu,
   list, panel and page.
9. Checks (coming). What the automated checks measure and what they
   reject.
