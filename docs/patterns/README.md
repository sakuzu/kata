# Patterns

A pattern is a shape of screen that comes back in every drawing
application: a form in a modal, a menu, a list with actions, a panel, a
settings page, the workbench. Each page below says which components make
it, the few rules that hold it together, and shows it working.

- [A modal with a form](modal-form.md): a task that stops the work, with
  fields, a check and one primary action.
- [A menu](menu.md): actions behind a button, on an item, and in the
  bar of the application.
- [A list with actions](list.md): items to find, select, act on and page
  through, and the empty list.
- [A panel](panel.md): a side of the screen with a head, groups that
  reach the edges and a foot.
- [A settings page](settings.md): tabs, groups of settings and a list of
  members.
- [A workbench](workbench.md): the shell with the layers, the stage, the
  tools and the inspector.

The patterns use only the [components](../components/README.md) and the
[workbench parts](../workbench/README.md); nothing on these pages is a
component of its own.
